# Aircraft Nose Landing Gear Design and Structural Analysis

## Overview

This project presents the CAD design and structural assessment of an aircraft nose landing gear assembly developed using SolidWorks and finite element analysis.

The objective is to design a lightweight and structurally efficient landing gear suitable for a light aircraft while maintaining an acceptable factor of safety.



## Features

- Complete nose landing gear assembly
- Oleo-pneumatic shock strut
- Dual wheel configuration
- Torque links
- Axle assembly
- Parametric CAD model
- Static structural analysis
- Buckling analysis
- Fatigue assessment
- Material comparison



## Software
