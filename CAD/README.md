# CAD Files

This folder contains the complete CAD models for the Aircraft Nose Landing Gear project.

## Folder Structure

- **Parts/** – Individual SolidWorks part files (.SLDPRT)
- **Assembly/** – Complete SolidWorks assembly (.SLDASM)
- **Drawings/** – Engineering drawings and technical documentation
- **STEP/** – Neutral CAD exchange files (.STEP)

## Software

- SolidWorks 2026 SP3.2 (Academic Version)

## Model Features

- Oleo-pneumatic shock strut
- Torque links (scissor links)
- Twin-wheel nose landing gear
- Wheel axle
- Mounting lugs
- Parametric design

The CAD model has been developed for educational and research purposes and serves as the basis for structural analysis and future design optimization.
